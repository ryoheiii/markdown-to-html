# markdown-to-html 初期仕様

2026-10-02の簡素化指示を反映。プロジェクト名は `markdown-to-html`、CLI名は `mdh`。

## 導入

- `git clone` → `node setup.js` → clone先の `bin` をPATHへ追加。
- Node.js 24.21以上・25未満、Pandoc 3.8以上・4未満は別途導入。
- npmパッケージ／tgz配布、npm link、グローバルnpmインストールは採用しない。
- OSS本体・取得済みライセンスはGit管理しない。setupが固定版を上流から取得し、ハッシュを確認して `.cache/` に保存する。
- 生成HTMLへのMermaidと必要なライセンスの埋め込みは維持する。

## 変換

Markdown → Pandoc JSON AST → 画像確認・Mermaidマーク → Pandoc HTML生成 → 完成ファイルの置換。

- UTF-8（BOM可）、LF/CRLF、GFM系の一般構文。
- 数式を解析しない。生HTMLは文字表示。独自Markdownパーサーなし。
- PNG/JPEG/GIF/WebP/依存のないSVG。相対画像パスは入力Markdown基準。
- 外部画像取得、欠落画像の無視、SVG依存の再帰収集はしない。
- 1入力→1HTML。既定は同じ場所の同名HTML。相対 `-o` は実行時cwd基準。
- 引数配列でPandocを起動し、一時ファイルへ出力。失敗時に既存HTMLを破壊しない。
- `--doctor` は依存・setup状態を確認。`--open` は生成後の補助で、起動失敗は警告。

## HTML

- `file://`・オフライン・元Markdownと元画像不在で本文・画像・目次・Mermaidを表示。
- 公式Mermaid 12.0.0の完成済みフル単一JSを、必要なHTMLに一度だけ埋め込む。
- 閲覧時に図ごとに描画。strict / baseの青系テーマ / dagre / classic / OSフォント。
- 独自config/CSS、画像・アイコン取り込みは非対応の図としてエラーとソースを表示。
- CLI成功と図の描画成功を区別。不正図でも他の本文・図・操作を継続。
- CSPで表示用の外部通信を抑止。通常のリンク先は同梱しない。
- ダークブルー単一テーマ、Pandocの見出しID・H1〜H3目次・構文ハイライト。
- コードは折り返さず内部スクロール。コピーは文字内容のみ、拒否時は手動案内。
- 子を持つ目次項目だけ開閉ボタン。JS無効時は展開済みリンクと図ソースを維持。
- 狭幅では目次を上部へ。大きい図・コード・表でページ全体を横にはみ出させない。

## 検証

Windows／Ubuntu／WSL、clone先からの起動、日本語・空白・記号パス、読み書き制限、既存出力保護、代表図と不正図、画像全形式、コピー拒否、目次、ライセンスを確認する。

ブラウザーは開発・CIテスト専用。新規コンテキストをofflineにし、元資料を削除したHTMLを確認する。未実施事項は検証記録に明記する。

通常変換用ブラウザー、独自バンドラー、常駐サーバー、独自VS Code拡張、数式、外部画像取得、PDF出力、監視、プラグイン基盤は追加しない。
